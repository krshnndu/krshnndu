### 🚀 Highlighted Projects & Architectures

- **🤖 Smart MCQ Solver (Transformer Fine-Tuning & Ensembling)**
  - Applied LoRA Parameter-Efficient Fine-Tuning (PEFT) on `microsoft/deberta-v3-base` and `roberta-base`.
  - Benchmarked multiple transformer configurations and constructed a 70:30 DeBERTa/RoBERTa ensemble targeting MAP@3 evaluation on Kaggle (0.742 MAP@3).

- **💬 Imbalanced Comment Classification & Hyperparameter Optimization**
  - Processed 198K comments across imbalanced classes using n-gram tokenization and statistical predictor screening (chi-square, Kruskal-Wallis).
  - Executed a 100-trial Optuna study on LightGBM with median-pruning and optimized class multipliers via Nelder-Mead to reach 0.831 F1-Macro.

- **📊 Enterprise Deal Analytics & HR Dashboards (Power BI)**
  - Built a 3-page Venture Capital portfolio dashboard with 50K fact records, star-schema data modeling, time-intelligence DAX measures, and decomposition tree AI visuals.
  - Developed an HR attrition analytics dashboard with 12 custom DAX measures for prior-quarter workforce comparisons.

- **⚙️ Full-Stack Enterprise Platform Engineering**
  - Spec-first architecture utilizing AWS Kiro EARS specifications to drive modular microservices.
  - Multi-host portable deployment (Docker, self-hosted AWS EC2 with PM2 and Nginx reverse proxy, Vercel, Render) backed by PostgreSQL.
